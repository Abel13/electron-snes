# Console library experience

After choosing a system, PixelCore behaves like that console rather than a desktop library manager.
Vertical navigation selects Library, Favorites, Recently played, or Controls without wrapping.
Horizontal navigation selects games: Library wraps, while Favorites and Recently played stop at their
ends. The selected game is centered as an original 3D cartridge with user artwork as its label.

The first confirmation reveals contextual actions and a second launches the game. Back closes detail
before returning to system selection. Global language and UI-audio preferences remain on the home;
only console input mapping appears under Controls. Filtering belongs to the desktop composition root,
so UI and core remain console-neutral.
