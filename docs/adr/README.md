# Architecture Decision Records (ADRs)

Pasta para decisões de arquitetura com impacto de longo prazo.

## Padrão

- Arquivos: `0001-descricao.md`, `0002-descricao.md`...
- Cada ADR deve explicar contexto, decisão, alternativas, consequências e status.
- Status aceitos: `proposto`, `aceito`, `substituído` e `rejeitado`.
- ADRs são obrigatórios para decisões de longo prazo sobre contratos públicos, dependências, segurança, armazenamento, input, emulação ou extensibilidade.
