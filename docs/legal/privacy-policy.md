# PixelCore Privacy Policy

**Effective date:** August 11, 2026

PixelCore is a local desktop application for playing legally obtained retro-game ROMs. This
policy explains what information PixelCore collects, where it is stored, and how it is used.

## Who controls the information

PixelCore is published by Abel Dutra UI.

Privacy contact: use the publisher contact options on the
[PixelCore GitHub repository](https://github.com/Abel13/electron-snes). Do not
include personal or sensitive information in a public issue.

## Information PixelCore stores

PixelCore is designed to work without an online account. The application stores the following
information locally on the user's device:

- user-selected ROM file references and library metadata;
- game titles, favorites, recently played entries, artwork references, and playtime;
- cartridge saves and save states;
- input profiles, controller assignments, and keyboard mappings;
- application, console, audio, language, and accessibility preferences;
- local diagnostic logs needed to troubleshoot the application.

ROM files, cartridge saves, and save states remain under the user's control. PixelCore does not
upload, distribute, or include commercial ROMs in the application.

## Information PixelCore does not collect

PixelCore does not intentionally collect or transmit:

- ROM contents or ROM hashes;
- save files or save-state contents;
- file paths outside the local device;
- controller identifiers for remote tracking;
- names, email addresses, contacts, or account credentials;
- advertising identifiers or precise location;
- microphone, camera, NFC, or telephony data.

## Diagnostics and telemetry

The initial release does not include a telemetry service. Local diagnostics are used only on the
device and are not sent to PixelCore by default. If a future release introduces telemetry, it will
be opt-in, described in the application, limited to a documented event catalog, and will not
include ROM content, saves, local paths, or unnecessary hardware identifiers.

## Third-party services and distribution

PixelCore may be distributed through GitHub Releases and the Microsoft Store. These platforms may
process information under their own privacy policies when users download, install, update, or
purchase the application. PixelCore does not receive the user's payment details from those
platforms.

The application does not require a PixelCore account or connect to a remote game catalog. Future
plugins and integrations must request explicit permissions and remain subject to the platform's
plugin security rules.

## Storage and deletion

Local data is stored in the application profile on the user's device. Users can remove library
entries, preferences, saves, and save states through the application where supported, or remove
the application's local data using their operating system's application-data controls. Removing
ROM references from the library does not delete the original ROM file unless the user explicitly
chooses an operation that says it will do so.

Uninstalling PixelCore may not remove all user data, depending on the operating system and the
installation channel. Users should export or back up any data they want to keep before uninstalling.

## Children's privacy

PixelCore is not directed at children under the age required by applicable law and does not
knowingly collect personal information from children.

## Security

PixelCore uses local storage boundaries, validated IPC, a minimal preload API, and explicit plugin
permissions. No security measure can guarantee absolute protection, so users should keep their
operating system and PixelCore installation up to date and use ROM files from trusted sources.

## International users

PixelCore can be used in multiple countries. Because the initial release does not operate a
telemetry service or remote account system, it does not intentionally transfer user data to a
PixelCore server. Store and hosting providers may process information according to their own
terms and regional requirements.

## Changes to this policy

We may update this policy when PixelCore's data practices change. The effective date at the top of
this document will be updated, and material changes will be communicated through the application
or its distribution page when appropriate.

## Contact

For privacy questions or requests, use the publisher contact options on the
[PixelCore GitHub repository](https://github.com/Abel13/electron-snes). Do not
include personal or sensitive information in a public issue.
